Lesson Vocabulary

Linear classifier
A model that combines weighted features to sort an item into one of two classes.
Class
One of the categories the model can predict.
Feature
A piece of information the model checks.
Weight
A number showing which direction a feature pushes the score and how strongly.
Score
The total after the model adds the weights of the features that are present.
Prediction
The class chosen by the model.
Label
The class we say an example should belong to.
Dataset
A collection of examples used to build, train, or test a model.
Train
Use labeled examples to improve a model.
Testing
Checking whether a model produces expected results by comparing its predictions to examples with known labels.
Inspect
Look closely at how and why the model made its predictions.
Evaluate
Judge how well the model performed and what should change.
